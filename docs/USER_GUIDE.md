# 手机配对与测试

## 1. 准备

- 安卓手机安装已支持远程访问的 Mika，第一版按 v0.1.35 协议验证。
- 在手机本地先完成 Mika 所需权限和模型配置，确认简单任务能够执行。
- 准备部署者提供的网关地址与管理员密钥。

如果自行部署，请先完成 [README 的部署步骤](../README.md)，再按本指南配对手机。文档中的示例域名需要替换成自己的网关地址。

本地 Mika 自身无法执行任务时，应先排查手机权限、模型或系统状态；网关只转发请求。

## 2. 生成配对码

1. 用手机或电脑浏览器打开网关根地址。
2. 输入单独提供的管理员密钥，进入管理页。
3. 点击生成配对码，复制页面显示的网关根地址和配对码。
4. 配对码有效期 5 分钟且只能成功使用一次；过期后重新生成。

管理员密钥仅在当前页面内存中保留。刷新页面或点击锁定后需要重新输入。

## 3. 安卓 Mika 配对

1. 打开 Mika 的远程访问设置。
2. 网关地址填写根地址，例如 `https://mika-relay.example.workers.dev`。
3. 输入刚生成的配对码，完成配对并启用远程连接。
4. 等待 Mika 显示远程在线，再到管理页点击刷新状态。

**手机的网关地址不要包含 `/mcp`。** `/mcp` 是外部 MCP 客户端使用的接口。

## 4. 电脑客户端配置

沿用 Mika 官方 CLI/MCP 客户端，在远程地址中使用网关提供的 URL。
MCP 端点为网关地址加 `/mcp`。

客户端请求应使用 **Mika 手机上生成的远程访问令牌**。
管理员密钥只管理网关，不能填入客户端当作手机访问令牌。

## 5. 建议验收顺序

| 步骤 | 操作 | 预期结果 |
| --- | --- | --- |
| 配对 | 完成上述步骤 | 手机与管理页都显示连接成功 |
| 简单任务 | 远程请求打开计算器并进行一次计算 | 手机执行，客户端能看到任务结果 |
| 空闲恢复 | 保持手机联网，闲置几分钟后再次发起简单任务 | 无需重新配对即可调用 |
| 网络切换 | 在 Wi-Fi 与移动网络之间切换，再等待重连 | 手机恢复在线，之后的任务可执行 |
| 锁屏 | 按手机端已配置的远程能力测试锁屏场景 | 行为与 Mika 自身的解锁/权限设置一致 |
| 手机离线 | 停止 Mika 远程连接后发起查询 | 客户端收到设备离线错误，不自动排队执行 |
| 撤销 | 管理页撤销设备 | 原设备凭据失效，需要新的配对码才能再次连接 |

若断线发生在任务提交途中，先查询任务原有 ID；不要为验证重连反复提交可能已执行的任务。

## 6. 遇到问题时提供什么

请记录：操作步骤、发生时间及所在时区、Mika 版本、手机网络类型、报错截图，
以及响应中的 `X-Request-Id`（若客户端能够看到）。无需提供管理员密钥、模型 API Key、
手机访问令牌或解锁密码。

`/healthz` 正常只代表网关可访问。手机是否在线应查看管理员状态页或手机远程连接状态。
